# v1.1.0 release validation

Checked on 19 September 2026. This pass validates implementation consistency and the recorded source correspondences. It does not certify measured station geometry or current equipment availability.

## Results

| Check | Result |
| --- | --- |
| Application regression suite | 28 passed, including source coverage/fingerprint, explicit lift stops, closures, floor corrections, registration and shared 2D/3D geometry. |
| Python geometry/import suite | Seven passed, including the published city polygons, holes, simplification and source-coordinate import. |
| Production build | Passed compilation, lint, TypeScript and static page generation. |
| Full geometry/source audit | Passed in the drawing and registered frames; all 3,101 compact city buildings checked against 122 decoded source tiles. |
| Production browser check | 3D station overview rendered; B2 plan and selected gate details worked; combined city geometry and GSI background rendered in 3D and north-up plan; source review showed v1.1.0 and pending photos. No browser errors were recorded. |

For each station frame the audit reports 59 valid slabs, 65 valid openings, eight building polygons, 20 attached exit anchors, 135 supported connector stops and 35 supported facilities. The [machine-readable audit](final-geometry-audit.json) records the source hashes and tolerances. The city payload is 645,153 bytes; the cached source archives are excluded from Git and the default browser load.

The build reported an older Browserslist dataset, and the browser reported the upstream Three.js Clock deprecation warning. Neither prevented compilation or rendering.

## Reproduce

```sh
npm ci
npm test
python -m pip install -r scripts/requirements-plateau.txt
python -m unittest discover -s tests -p 'test_*.py'
npm run build
node scripts/report-station-alignment.mjs
```

The full source audit additionally needs the cached PLATEAU tiles described in [the area notes](geographic-area.md):

```sh
python scripts/check_geometry_alignment.py
```

The release-branch GitHub workflow repeats the application tests, Python tests and production build on Linux. It does not download the full source cache or substitute for the locally recorded source audit.

## Deferred evidence

The station's horizontal fit remains provisional: 25.7 m RMS against three building centres, with no independent surveyed entrance checkpoints or measured floor elevations. Five building matches, some equipment identities/stops, gate boundaries and current operation remain unresolved. These limitations are retained in the interface and [source-correction report](source-corrections.md).

Photo verification is explicitly deferred until after v1.1.0. The [photo checklist](photo-verification.md) records the requested views and how later evidence should be applied. Ordinary photographs can confirm identities and dated conditions; precise geographic placement requires measured plans or survey coordinates.
